## Overview

**RajLibAuth** is a premium, clean authentication portal with a library-themed design. It features a split layout with a high-quality library stock image on the left and a clean form panel on the right with pill-shaped inputs, social login options, and complete signup/login functionality with local storage persistence.

### Objectives
- **Professional Design:** Clean, library-themed aesthetic
- **Dual Authentication:** Sign up and Sign in functionality
- **User Management:** LocalStorage for user database
- **Session Management:** Secure session storage
- **Personalized Dashboard:** Welcome message with user name
- **Social Login:** Google and Facebook demo buttons

## Key Features

### Authentication System
- **Sign Up:** Create new account with username and password
- **Sign In:** Login with existing credentials
- **Session Management:** Secure session storage
- **Logout:** Clear session and return to login
- **User Persistence:** LocalStorage for user database
- **Social Login:** Google and Facebook demo buttons

### Visual Design
- Pink to purple gradient background
- Premium library stock image on left panel
- Clean white form panel with pill-shaped inputs
- Purple accent color (#8721f8)
- Smooth transitions and animations

### Dashboard
- Personalized welcome message
- Secure Local DB widget
- Clean Aesthetics widget
- Library Environment widget

### Notifications
- Toast notifications for all actions
- Color-coded feedback (success, error, info)
- Auto-dismiss after 3 seconds
